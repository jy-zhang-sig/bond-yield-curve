## 三、部署到 GitHub Pages（家里电脑，需能访问 GitHub）

### 前置条件（家里电脑装一次）
- 安装 **Git for Windows**：https://git-scm.com/download/win （自带 Git Bash）
- 对 `harry-li-sf/Bond-yield-curve` 仓库有**写权限**（是 owner 或被加为 Collaborator）

### 部署步骤（1 步）
1. 解压本包到任意目录
2. 在解压后的文件夹里**右键空白处 → Git Bash Here**
3. 在 Git Bash 里运行：
   ```bash
   bash deploy_to_github.sh
   ```
4. 脚本自动：克隆仓库 → 复制 7 个修改/新增文件 → 提交 → 推送
5. **首次推送会弹出 GitHub 登录/授权**，按提示登录（或填 Personal Access Token，需 `repo` 权限）
6. 推送成功后，GitHub Actions 自动部署到 Pages

### 部署后
- 访问：**https://harry-li-sf.github.io/Bond-yield-curve/** （按 `Ctrl+F5` 强刷）
- 每工作日 cron 自动抓取中债登数据并部署（`ci_update.py`/`update-data.yml` 未改动，原站每日自动更新机制完整保留）
- 第三板块「预定利率研究值」的 `data/predictions.json` 为静态快照（2026-07-21），如需持续更新可后续扩展 CI（Phase B，可另行处理）

## 五、如部署失败

- **推送被拒（远端有新提交）**：脚本已自动 `git pull --rebase` 后重试，通常无需干预。
- **无写权限**：改为 fork 仓库 → 推 fork → 发 PR 合并。
- **端口 8000 被占**：preview.bat 改端口或关占用程序。
- 其余问题可把 Git Bash 里的报错截图发我。
